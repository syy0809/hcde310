## Resource 1: Open-Meteo Weather Forecast API

**What it provides** (1–2 sentences):

Open-Meteo provides weather forecast data, including temperature, humidity, precipitation probability, and daily weather conditions. It allows developers to retrieve weather information for specific geographic locations.

**Docs link:** https://open-meteo.com/en/docs

**Access:** API key needed? Rate limits? Cost? (write "none" if none)

API key: Not required for the free non-commercial API.

Rate limits: The free non-commercial tier allows up to 10,000 requests per day, subject to additional shorter-term limits.

Cost: Free for qualifying non-commercial use; paid plans are available.

**Sample response** (trim it to a few fields; paste the URL you called too):

URL: https://api.open-meteo.com/v1/forecast?latitude=47.6062&longitude=-122.3321&current=temperature_2m%2Crelative_humidity_2m&hourly=temperature_2m%2Cprecipitation_probability&daily=temperature_2m_max%2Ctemperature_2m_min%2Cprecipitation_sum&timezone=America%2FLos_Angeles

```json
{
  "latitude": 47.595562,
  "longitude": -122.32443,
  "timezone": "America/Los_Angeles",
  "current": {
    "time": "2026-10-27T16:30",
    "interval": 900,

    "relative_humidity_2m": 80
  }

```

**Who could this data help, and with what?** (2–3 ideas; name real people and a real need, e.g. "first-year students who want to ...")

1. UW students who walk between classes could use hourly precipitation forecasts to decide when to leave their dorms and whether to bring an umbrella.
2. Students who bike to campus could compare weather conditions throughout the day to choose more comfortable commuting times.
3. UW student organizations planning outdoor events could use daily forecasts to select suitable event dates and prepare indoor backup plans.

**One risk** (missing data, bias, privacy, or reliability):

Weather forecasts may sometimes be inaccurate because weather conditions in Seattle can change unexpectedly. Students who rely too heavily on these forecasts may make poor decisions about commuting or planning outdoor activities.


## Resource 2: Open Library Search API

**What it provides** (1–2 sentences):

Open Library Search API provides information about books, including their titles, authors, publication years, and cover images. Users can search for books by keywords to discover relevant reading materials.

**Docs link:** https://openlibrary.org/dev/docs/api/search

**Access:** API key needed? Rate limits? Cost? (write "none" if none)

No API key is required for basic public searches. The API is free to use, but requests are subject to usage limits.
